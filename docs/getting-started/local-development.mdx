# Local Development

Run the canonical Protocol Tooling engine, database migrations, seed data, and REST API locally.

---

## Prerequisites

* **Node.js**: v22.12 or newer (Node 24+ recommended)
* **PostgreSQL**: Local PostgreSQL 15+ or a hosted connection string (e.g. PlanetScale Postgres or Neon)
* **Git** & **npm**

---

## Clone and Setup Core Repository

```bash
git clone https://github.com/robertonevarez/protocoltooling.git
cd protocoltooling
npm install
```

---

## Environment Configuration

Create a `.env.local` file in the root of `protocoltooling`:

```bash
# PostgreSQL Connection URL
DATABASE_URL="postgresql://postgres:postgres@localhost:5432/protocoltooling"

# Optional: Port configuration
PORT=3000
```

---

## Running Migrations & Seeding

The core repository contains migrations for the relational schema and 5 canonical business archetypes:

```bash
# Run database schema migrations
npm run db:migrate

# Seed canonical businesses (Acme HVAC, Blue Pipe Plumbing, Northline Salon, Harbor PT, Mesa Auto)
npm run db:seed
```

---

## Starting the API Server

```bash
npm run dev
```

The core Next.js API server will start on `http://localhost:3000`.

You can verify the health and tools of a seeded business:

```bash
curl -X POST http://localhost:3000/api/businesses/acme-hvac/search-services \
  -H "Content-Type: application/json" \
  -d '{"query": "diagnostic"}'
```

Response:

```json
{
  "ok": true,
  "data": [
    {
      "id": "svc_ac_diagnostic",
      "business_id": "biz_acme_hvac",
      "name": "AC Diagnostic Visit",
      "duration_minutes": 90,
      "price_cents": 8900,
      "currency": "USD",
      "service_area_required": true
    }
  ]
}
```
