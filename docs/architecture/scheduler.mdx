# Domain Scheduler

The domain scheduler (`src/domain/scheduler.ts`) contains pure, deterministic algorithms for generating available appointment slots.

---

## Core Algorithms

### 1. Working Hours Matching
Calculates whether a candidate UTC interval `[starts_at, ends_at]` falls entirely within the business's open hours in its local timezone:

```ts
export function isWithinWorkingHours(
  startUtc: Date,
  endUtc: Date,
  workingHours: WorkingHours[],
  timezone: string
): boolean
```

### 2. Time Preference Filtering
Filters candidate slots according to customer preferences:
* `morning`: Starts before 12:00 PM local time.
* `afternoon`: Starts between 12:00 PM and 5:00 PM local time.
* `evening`: Starts at or after 5:00 PM local time.
* `any`: All operating intervals.

### 3. Resource Allocation Engine
Matches service resource requirements against available staff and facilities, excluding overlapping appointments and blocked breaks.
