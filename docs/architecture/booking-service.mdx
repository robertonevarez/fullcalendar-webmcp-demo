# BookingService

`BookingService` is the central orchestrator in Protocol Tooling. It mediates between the HTTP API endpoints and the domain scheduler / database repositories.

---

## Responsibilities

* **Domain Validation**: Resolves business slugs, verifies active services, and enforces required fields.
* **Context Construction**: Loads business hours, assigned resources, existing appointments, and blocked periods into a `SchedulerContext`.
* **Service Area Filtering**: Evaluates postal code zones against requested services.
* **Slot Revalidation**: Re-verifies that a tokenized `slot_id` remains available before committing.
* **Idempotency Guard**: Ensures client retries do not create duplicate appointments.

---
