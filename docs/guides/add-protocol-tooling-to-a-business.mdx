# Add Protocol Tooling to a Business Website

Learn how to make an existing service business bookable by personal AI agents in three steps.

---

## Step 1: Configure the Business Record

Ensure your business, services, and resources are registered in Protocol Tooling.

For example, using the core API or migration seed:
* Business slug: `acme-hvac`
* Services: AC Diagnostic, AC Repair, Preventive Maintenance
* Resources: Technicians with assigned capability tags

---

## Step 2: Include the WebMCP Client Adapter

Install or import the WebMCP registration module on your frontend website:

```bash
npm install @protocoltooling/webmcp
```

---

## Step 3: Register Tools on Page Mount

Add the registration snippet to your client entrypoint (e.g. `App.tsx`, layout component, or vanilla JavaScript script tag):

```ts
import { registerBusinessToolsWhenReady } from '@protocoltooling/webmcp';

// Automatically bind tools to document.modelContext
registerBusinessToolsWhenReady({
  businessSlug: 'acme-hvac',
  businessName: 'Acme Heating & Air',
  apiBaseUrl: 'https://api.protocoltooling.com',
});
```

When an agentic browser visits your website, it discovers the 8 tools and can immediately search, verify service areas, query availability, and book appointments.
