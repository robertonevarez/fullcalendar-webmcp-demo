# search_services

### Purpose
Searches and filters active bookable services offered by the business matching a user query or general intent.

---

### When to Call
Call this tool first when a customer expresses a desire to book or asks about available services, prices, or capabilities.

---

### Tool Declaration & Schema

```json
{
  "name": "search_services",
  "description": "Search bookable services for the business.",
  "inputSchema": {
    "type": "object",
    "properties": {
      "query": {
        "type": "string",
        "description": "Search query or keyword (e.g. 'AC diagnostic', 'haircut', 'clogged drain')"
      }
    },
    "additionalProperties": false
  },
  "annotations": {
    "readOnlyHint": true
  }
}
```

---

### Example Input & Output

**Tool Call**:
```json
{
  "query": "ac not cooling"
}
```

**Tool Response**:
```json
{
  "ok": true,
  "data": [
    {
      "id": "svc_ac_diagnostic",
      "business_id": "biz_acme_hvac",
      "name": "AC Diagnostic Visit",
      "description": "Technician inspects cooling performance, airflow, and refrigerant indicators.",
      "duration_minutes": 90,
      "price_cents": 8900,
      "currency": "USD",
      "keywords": ["AC", "cooling", "not cooling", "airflow", "diagnostic"],
      "location_policy": "CUSTOMER",
      "service_area_required": true,
      "intake_fields": ["issue_description", "symptom_location"]
    }
  ]
}
```

---

### Expected Domain Errors
* `BUSINESS_NOT_FOUND`: The business slug does not resolve to an active business record.

### Underlying REST Endpoint
`POST /api/businesses/:slug/search-services`
