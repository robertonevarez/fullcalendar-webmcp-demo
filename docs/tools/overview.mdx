# WebMCP Tools Reference Overview

Protocol Tooling specifies **8 canonical WebMCP tools**. These tools provide complete coverage for discovering services, evaluating availability, and managing the appointment lifecycle.

---

## Canonical Tool Summary

| Tool Name | Action Type | Annotations | Side Effects | Underlying Endpoint |
|---|---|---|---|---|
| [`search_services`](/tools/search-services) | Read-only | `readOnlyHint: true` | None | `POST /api/businesses/:slug/search-services` |
| [`get_service_details`](/tools/get-service-details) | Read-only | `readOnlyHint: true` | None | `POST /api/businesses/:slug/get-service-details` |
| [`check_service_area`](/tools/check-service-area) | Read-only | `readOnlyHint: true` | None | `POST /api/businesses/:slug/check-service-area` |
| [`get_availability`](/tools/get-availability) | Read-only | `readOnlyHint: true` | None | `POST /api/businesses/:slug/get-availability` |
| [`create_appointment`](/tools/create-appointment) | Mutation | `readOnlyHint: false` | Creates booking & locks resources | `POST /api/businesses/:slug/create-appointment` |
| [`get_appointment`](/tools/get-appointment) | Read-only | `readOnlyHint: true` | None | `POST /api/businesses/:slug/appointments/get` |
| [`reschedule_appointment`](/tools/reschedule-appointment) | Mutation | `readOnlyHint: false` | Updates booking & moves resource locks | `POST /api/businesses/:slug/appointments/reschedule` |
| [`cancel_appointment`](/tools/cancel-appointment) | Mutation | `readOnlyHint: false` | Cancels booking & frees resources | `POST /api/businesses/:slug/appointments/cancel` |

---

## Shared Data Formats

* **Monetary Values**: All prices are expressed in integer cents (`price_cents: 8900` = $89.00).
* **Timestamps**: All start and end times are represented in ISO 8601 UTC strings (`2026-09-01T15:00:00.000Z`).
* **Identifiers**:
  - `service_id`: `svc_...`
  - `resource_id`: `res_...`
  - `slot_id`: `slot_...`
  - `appointment_id`: `appt_...`
