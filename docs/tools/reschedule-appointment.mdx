# reschedule_appointment

### Purpose
Atomically shifts an existing confirmed appointment to a newly selected availability slot ID.

---

### When to Call
:::important
**Human confirmation required.** Query `get_availability` first to retrieve a `new_slot_id`, confirm the new time with the user, and then execute this tool.
:::

---

---

### Expected Domain Errors
* `APPOINTMENT_NOT_FOUND`: Appointment does not exist.
* `APPOINTMENT_NOT_RESCHEDULABLE`: The appointment is in `cancelled` status.
* `SLOT_UNAVAILABLE`: The target new slot has expired or is no longer available.

### Underlying REST Endpoint
`POST /api/businesses/:slug/appointments/reschedule`
