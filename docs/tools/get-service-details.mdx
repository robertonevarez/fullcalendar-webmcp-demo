# get_service_details

### Purpose
Fetches complete service configuration, duration, pricing, intake requirements, and location policies for a specific `service_id`.

---

### When to Call
Call this tool when the agent needs full details on a known `service_id` (e.g. after selection from search results or when inspecting required intake questions).

---

### Tool Declaration & Schema

```json
{
  "name": "get_service_details",
  "description": "Get detailed service information including duration, pricing, and requirements.",
  "inputSchema": {
    "type": "object",
    "properties": {
      "service_id": {
        "type": "string",
        "description": "Unique identifier of the service (e.g. 'svc_ac_diagnostic')"
      }
    },
    "required": ["service_id"],
    "additionalProperties": false
  },
  "annotations": {
    "readOnlyHint": true
  }
}
```

---

### Example Input & Output

**Tool Call**:
```json
{
  "service_id": "svc_ac_diagnostic"
}
```

**Tool Response**:
```json
{
  "ok": true,
  "data": {
    "id": "svc_ac_diagnostic",
    "business_id": "biz_acme_hvac",
    "name": "AC Diagnostic Visit",
    "description": "Technician inspects cooling performance, airflow, and refrigerant indicators.",
    "duration_minutes": 90,
    "price_cents": 8900,
    "currency": "USD",
    "location_policy": "CUSTOMER",
    "service_area_required": true,
    "resource_requirements": [
      {
        "resource_type": "hvac_technician",
        "quantity": 1,
        "capability": "hvac_diagnostic"
      }
    ],
    "intake_fields": ["issue_description", "symptom_location"]
  }
}
```

---

### Expected Domain Errors
* `SERVICE_NOT_FOUND`: The requested `service_id` does not exist for this business.

### Underlying REST Endpoint
`POST /api/businesses/:slug/get-service-details`
