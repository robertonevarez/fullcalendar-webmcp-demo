# get_appointment

### Purpose
Retrieves current appointment status, timing, customer details, and assigned resource information by appointment ID.

---

### When to Call
Call this tool when a customer asks to check their existing booking or before initiating a reschedule or cancellation request.

---

### Tool Declaration & Schema

```json
{
  "name": "get_appointment",
  "description": "Fetch appointment details and status by appointment ID.",
  "inputSchema": {
    "type": "object",
    "properties": {
      "appointment_id": {
        "type": "string",
        "description": "The unique appointment ID (e.g. 'appt_9b7c81df')"
      }
    },
    "required": ["appointment_id"],
    "additionalProperties": false
  },
  "annotations": {
    "readOnlyHint": true
  }
}
```

---

### Expected Domain Errors
* `APPOINTMENT_NOT_FOUND`: No appointment with this ID exists for the business.

### Underlying REST Endpoint
`POST /api/businesses/:slug/appointments/get`
