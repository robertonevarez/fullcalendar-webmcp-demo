# get_availability

### Purpose
Queries authoritative booking slots for a service across a date range, matching working hours, time preferences, and multi-resource requirements.

---

### When to Call
Call this tool when the customer provides their desired dates (e.g. "next Tuesday or Wednesday morning") to retrieve concrete `slot_id` tokens.

---

### Tool Declaration & Schema

```json
{
  "name": "get_availability",
  "description": "Find available appointment slots for a service within a date range.",
  "inputSchema": {
    "type": "object",
    "properties": {
      "service_id": { "type": "string" },
      "start_date": { "type": "string", "description": "Start date (YYYY-MM-DD)" },
      "end_date": { "type": "string", "description": "End date (YYYY-MM-DD)" },
      "postal_code": { "type": "string", "description": "Required for customer-location services" },
      "preferred_resource_id": { "type": "string", "description": "Optional staff or room ID" },
      "time_preference": {
        "type": "string",
        "enum": ["morning", "afternoon", "evening", "any"],
        "description": "Filter by time of day"
      }
    },
    "required": ["service_id", "start_date", "end_date"],
    "additionalProperties": false
  },
  "annotations": {
    "readOnlyHint": true
  }
}
```

---

### Example Input & Output

**Tool Call**:
```json
{
  "service_id": "svc_ac_diagnostic",
  "start_date": "2026-09-01",
  "end_date": "2026-09-02",
  "postal_code": "78704",
  "time_preference": "morning"
}
```

**Tool Response**:
```json
{
  "ok": true,
  "data": [

      "ends_at": "2026-09-01T10:30:00.000Z",
      "resources": [
        {
```

---

### Expected Domain Errors
* `LOCATION_REQUIRED`: Missing postal code when required.
* `OUTSIDE_SERVICE_AREA`: Postal code is not served.
* `INVALID_TIME_RANGE`: `start_date` occurs after `end_date`.
* `NO_AVAILABILITY`: No satisfiable resource combinations exist in the window.

### Underlying REST Endpoint
`POST /api/businesses/:slug/get-availability`
