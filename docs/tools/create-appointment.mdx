# create_appointment

### Purpose
Authoritatively creates a confirmed appointment using a selected availability `slot_id`.

---

### When to Call
:::important
**Human confirmation required.** Call this tool only after presenting the slot time, address, and pricing to the user and receiving explicit consent.
:::

---

### Expected Domain Errors
* `SLOT_UNAVAILABLE`: The slot has expired or was booked by another transaction.
* `RESOURCE_UNAVAILABLE`: A required resource has a conflicting commitment.
* `OUTSIDE_SERVICE_AREA`: Address postal code is not eligible.
* `IDEMPOTENCY_CONFLICT`: The key was previously used with a different request payload.

### Underlying REST Endpoint
`POST /api/businesses/:slug/create-appointment`
